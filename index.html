      📚 Data Sources

      LIVE MAP

      OpenStreetMap / Leaflet

      Used for interactive map display and tiles.

      LIVE / API

      Place Search

      Any place name is geocoded live via OpenStreetMap Nominatim — not limited to a fixed town list.

      LIVE / SATELLITE (optional backend)

      Fishing Suitability — Satellite tier

      When the included Python backend (backend/main.py) is running, fish-suitability is computed from REAL satellite Sea-Surface Temperature and Chlorophyll-a (NOAA CoastWatch ERDDAP) — the same two signals INCOIS's official PFZ advisories are built on. Without the backend running, this falls back to the Weather-only tier below, then to the fully simulated tier — check the SATELLITE / LIVE / SIM badge on each zone card to see which applied.

      LIVE / API (fallback: estimate)

      Weather & Waves

      Wind, sea-surface temperature and wave height are fetched live from Open-Meteo where available; falls back to an estimated value if the request fails.

      ESTIMATED

      ORCA Fishing Suitability

      Fallback fish-suitability score used only when neither the satellite backend nor Open-Meteo are reachable.

      TREATY-BASED

      Boundary Data

      India–Sri Lanka line uses the real coordinate points from the 1974 Palk Strait and 1976 Gulf of Mannar agreements. State boundary lines are a rough coastal-latitude approximation. Neither is a substitute for an official chart — always verify with authorities.

      ESTIMATED

      Family Alerts

      SMS/call notifications are logged only — no real message or call is sent by this app yet.

      HEURISTIC

      Cyclone Intelligence

      The storm-risk number uses real live wind, pressure and wave data (same Open-Meteo source as elsewhere), combined into a simple heuristic — not real cyclone detection or tracking. Always check IMD and INCOIS directly for official cyclone warnings.

      REAL GEOGRAPHY

      Seaward Candidate Zones

      Candidate zone bearings are constrained to a realistic seaward cone based on which Indian coast (Bay of Bengal or Arabian Sea) the selected point is on, instead of a uniformly random 0-360° bearing that could occasionally point back toward land.

      REFERENCE

      Known Fishing Harbors

      A small curated list of real, publicly known major Indian fishing harbors, shown as map markers and a "nearest harbor" fact. General-knowledge positions, not survey-grade coordinates and not a live feed.

      REAL DATASET (simplified)

      State Boundaries & Water Bodies

      Real, public GADM-derived India state/UT boundaries and Natural Earth lakes & rivers, simplified and clipped to India — community/public-domain geographic datasets, not official survey charts.
